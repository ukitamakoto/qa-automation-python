# BUG-003: Add to cart does nothing for 3 of the 6 products

| Field | Value |
|---|---|
| Target | SauceDemo · https://www.saucedemo.com |
| User | `problem_user` and `error_user` |
| Severity | High: half of the catalogue cannot be bought |
| Priority | High |
| Environment | Chromium 156.0.8078.4 and Firefox 157.0 via Playwright 1.64, headless (macOS locally, Ubuntu in CI) |
| Found | 2026-10-14 |
| Reproduced by | `tests/ui/test_inventory.py::test_every_product_can_be_added_to_the_cart` for both users (strict xfail) |

## Steps to reproduce
1. Log in with `problem_user` / `secret_sauce`. (same result with `error_user`).
2. Click Add to cart on all 6 products.
3. Read the cart badge.

## Expected
The badge shows 6 and every button switches to Remove.

## Actual
The badge shows 3. Add to cart does nothing for Sauce Labs Bolt T-Shirt, Sauce Labs Fleece Jacket and Test.allTheThings() T-Shirt (Red): their buttons never switch to Remove.
