# BUG-004: Typing in Last Name overwrites First Name

| Field | Value |
|---|---|
| Target | SauceDemo · https://www.saucedemo.com |
| User | `problem_user` |
| Severity | High: checkout is blocked |
| Priority | High |
| Environment | Chromium 156.0.8078.4 and Firefox 157.0 via Playwright 1.64, headless (macOS locally, Ubuntu in CI) |
| Found | 2026-10-14 |
| Reproduced by | `tests/ui/test_checkout.py::test_problem_user_can_fill_the_checkout_form` (strict xfail) |

## Steps to reproduce
1. Log in with `problem_user` / `secret_sauce`.
2. Add Sauce Labs Backpack → Cart → Checkout.
3. Type `Ana` in First Name, `Silva` in Last Name and `8000-123` in Postal Code.
4. Click Continue.

## Expected
First Name `Ana`, Last Name `Silva`; Continue opens the order overview.

## Actual
First Name shows `Silva` and Last Name stays empty; Continue fails with `Error: Last Name is required`.
