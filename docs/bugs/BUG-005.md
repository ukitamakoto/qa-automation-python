# BUG-005: Sorting raises an error alert and does not sort

| Field | Value |
|---|---|
| Target | SauceDemo · https://www.saucedemo.com |
| User | `error_user` |
| Severity | Medium: sorting is unusable and the user sees an error dialog |
| Priority | Medium |
| Environment | Chromium 156.0.8078.4 and Firefox 157.0 via Playwright 1.64, headless (macOS locally, Ubuntu in CI) |
| Found | 2026-10-14 |
| Reproduced by | `tests/ui/test_inventory.py::test_error_user_can_sort_without_an_error_alert` (strict xfail) |

## Steps to reproduce
1. Log in with `error_user` / `secret_sauce`.
2. Choose `Name (Z to A)` in the sort menu.

## Expected
The list is reordered Z→A and no dialog appears.

## Actual
A JavaScript alert says `Sorting is broken! This error has been reported to Backtrace.` and the list stays in A→Z order.
