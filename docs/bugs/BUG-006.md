# BUG-006: Last Name ignores typing and checkout continues without it

| Field | Value |
|---|---|
| Target | SauceDemo · https://www.saucedemo.com |
| User | `error_user` |
| Severity | High: orders are accepted with a required field missing |
| Priority | High |
| Environment | Chromium 156.0.8078.4 and Firefox 157.0 via Playwright 1.64, headless (macOS locally, Ubuntu in CI) |
| Found | 2026-10-14 |
| Reproduced by | `tests/ui/test_checkout.py::test_error_user_checkout_keeps_the_last_name` (strict xfail) |

## Steps to reproduce
1. Log in with `error_user` / `secret_sauce`.
2. Add Sauce Labs Backpack → Cart → Checkout.
3. Type `Ana`, `Silva`, `8000-123` in First Name, Last Name and Postal Code.
4. Click Continue.

## Expected
Last Name keeps `Silva`; Continue is refused while it is empty.

## Actual
Last Name stays empty after typing, and Continue still opens the order overview (`checkout-step-two`) without a last name.
