# BUG-007: Finish does not complete the order

| Field | Value |
|---|---|
| Target | SauceDemo · https://www.saucedemo.com |
| User | `error_user` |
| Severity | High: the order can never be placed |
| Priority | High |
| Environment | Chromium 156.0.8078.4 and Firefox 157.0 via Playwright 1.64, headless (macOS locally, Ubuntu in CI) |
| Found | 2026-10-14 |
| Reproduced by | `tests/ui/test_checkout.py::test_error_user_can_finish_the_order` (strict xfail) |

## Steps to reproduce
1. Log in with `error_user` / `secret_sauce`.
2. Add Sauce Labs Backpack → Cart → Checkout → fill the form → Continue.
3. Click Finish.

## Expected
The confirmation page opens with `Thank you for your order!`.

## Actual
Nothing happens: the page stays on `checkout-step-two` and no confirmation is shown.
