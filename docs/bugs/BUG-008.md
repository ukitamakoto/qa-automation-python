# BUG-008: Listing prices differ from the price charged in the cart

| Field | Value |
|---|---|
| Target | SauceDemo · https://www.saucedemo.com |
| User | `visual_user` |
| Severity | High: the customer is shown one price and charged another |
| Priority | High |
| Environment | Chromium 156.0.8078.4 and Firefox 157.0 via Playwright 1.64, headless (macOS locally, Ubuntu in CI) |
| Found | 2026-10-14 |
| Reproduced by | `tests/ui/test_inventory.py::test_visual_user_listing_price_matches_the_cart` (strict xfail) |

## Steps to reproduce
1. Log in with `visual_user` / `secret_sauce`.
2. Note the price of Sauce Labs Backpack on the inventory page.
3. Add it to the cart and open the cart.

## Expected
The cart shows the same price as the listing.

## Actual
The cart charges `$29.99`, but the listing shows a different, random price on every load (observed `$26.51`, `$41.18`, `$53.73` and `$37.48` in four runs).
