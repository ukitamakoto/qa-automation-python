# BUG-009: Wrong credentials return 200 instead of 401

| Field | Value |
|---|---|
| Target | Restful-Booker · https://restful-booker.herokuapp.com |
| Endpoint | `POST /auth` |
| Severity | Medium: clients and monitoring cannot rely on the status code to detect a failed login |
| Priority | Medium |
| Environment | Public Restful-Booker instance, HTTP via requests 2.34 |
| Found | 2026-10-14 |
| Reproduced by | `tests/api/test_auth.py::test_wrong_credentials_return_401_without_a_token` (strict xfail) |

## Steps to reproduce
1. `POST /auth` with body `{"username": "admin", "password": "wrong-password"}`.

## Expected
`401 Unauthorized` and no token.

## Actual
`200 OK` with body `{"reason": "Bad credentials"}` (no token is issued).
