# BUG-010: DELETE answers 201 Created

| Field | Value |
|---|---|
| Target | Restful-Booker · https://restful-booker.herokuapp.com |
| Endpoint | `DELETE /booking/{id}` |
| Severity | Low: misleading status code for a deletion |
| Priority | Low |
| Environment | Public Restful-Booker instance, HTTP via requests 2.34 |
| Found | 2026-10-14 |
| Reproduced by | `tests/api/test_booking.py::test_delete_answers_with_a_success_status` (strict xfail) |

## Steps to reproduce
1. Create a booking with `POST /booking`.
2. Get a token with `POST /auth` (admin / password123).
3. `DELETE /booking/{id}` with the cookie `token=<token>`.

## Expected
`200 OK` or `204 No Content`.

## Actual
`201 Created` with body `Created`. The booking is deleted (a later `GET` returns 404).
