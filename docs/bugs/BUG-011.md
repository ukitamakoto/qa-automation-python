# BUG-011: A booking without firstname crashes the server

| Field | Value |
|---|---|
| Target | Restful-Booker · https://restful-booker.herokuapp.com |
| Endpoint | `POST /booking` |
| Severity | Medium: invalid input causes a server error instead of a validation message |
| Priority | Medium |
| Environment | Public Restful-Booker instance, HTTP via requests 2.34 |
| Found | 2026-10-14 |
| Reproduced by | `tests/api/test_booking.py::test_missing_required_field_is_a_client_error` (strict xfail) |

## Steps to reproduce
1. `POST /booking` with a complete booking body minus the `firstname` field.

## Expected
`400 Bad Request` naming the missing field.

## Actual
`500 Internal Server Error`.
