# BUG-012: Impossible bookings are accepted

| Field | Value |
|---|---|
| Target | Restful-Booker · https://restful-booker.herokuapp.com |
| Endpoint | `POST /booking` |
| Severity | Medium: data integrity; a stay that ends before it starts is stored |
| Priority | Medium |
| Environment | Public Restful-Booker instance, HTTP via requests 2.34 |
| Found | 2026-10-14 |
| Reproduced by | `tests/api/test_booking.py::test_impossible_booking_is_rejected` (strict xfail) |

## Steps to reproduce
1. `POST /booking` with `"totalprice": -5` and `"bookingdates": {"checkin": "2026-11-05", "checkout": "2026-11-01"}`.

## Expected
`400 Bad Request`: check-out must be after check-in and the price cannot be negative.

## Actual
`200 OK`; the booking is created and returned with the impossible dates and the negative price.
